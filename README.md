# Generador_Voronoi_3D
Generador de una mezcla de agregados y matriz realizado en Python a través del enfoque de diagrama de Voronoi.

Para ejecutar el código, es necesario instalar previamente las librerías requeridas, las cuales se encuentran especificadas en el archivo requirements.txt. Para ello, debe ubicarse en la carpeta desde la cual se ejecutará el código y, una vez situada en dicha ruta, ingresar en la terminal del programa o editor de código el siguiente comando: pip install -r requirements.txt.

Posteriormente, en el código, de la línea 22 a la 61, es la sección correspondiente a los parámetros necesarios para la generación de la mezcla Voronoi.

Las variables "B", "H" y "D", se refieren a la base, ancho y altura del volumen del control respectivamente. La variable "frac_agregado" corresponde al porcentaje de agregado que se desea respecto al volumen de control. Para insertar un nuevo agregado, se debe agregar una línea adicional a la variable tipo lista "tipos_agregado" y se ingresa como dupla la siguiente información: ("nombre agregado", diámetro mínimo en [mm], diámetro máximo en [mm], porcentaje de agregado). Es importante que la suma de porcentajes de cada tipo de agregado sume 1. Las variables relacionadas a las formas de las partículas, "elongacion" y "aplanamiento", tienen un factor mayor a 1 y menor a 1 respectivamente y a su vez, cada una de estas variables tienen una variable correspondiente al porcentaje de partículas que se quieren elongar o aplanar. El resto de variables se recomienda no modificar; en caso de obtener una malla NO OK, si es preferible modificar estos parámetros: se recomienda cambiar "n_matriz_obj" y "sep_agregados" (en mm).
